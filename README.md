# Sito Mistail

Sito pubblicato con GitHub Pages su https://mistail.com

- `index.html` – pagina principale
- `privacy/index.html` – privacy policy di Lux Tower (IT + EN)
- `robots.txt` + meta `noindex` – i motori di ricerca non indicizzano il sito finché il gioco non esce (da togliere al lancio)
- `CNAME` – dominio personalizzato
- `app-ads.txt` – da aggiungere con le righe di LevelPlay prima del lancio
